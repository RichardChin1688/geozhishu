## 0. 这份文档存在的理由

2026 年 3 月 15 日，总台「3·15」晚会曝光了 AI 语料投毒的灰色产业链：一款名叫「力擎 GEO 优化系统」的软件，可以批量生成十余篇虚假软文并全网发布，随后一款**并不存在**的智能手环「Apollo-9」，被两家主流大模型作为推荐答案输出。

这件事暴露的不是某一家公司的问题，而是整个 GEO 行业缺少一样东西：**一把可以被检查的尺子**。

GEO指数 存在的目的，就是把尺子公开。

本文件完整披露 GEO指数 的计算方法、采样协议、样本构成、权重设定与变更历史。任何人可以按照本文件，独立复现我们发布的每一个数字。凡不能复现的，我们视为我们的错误。

## 1. 什么是 GEO 指数

GEO 指数（GEO Index）是一个 0–100 分的综合度量，用于描述**一个企业或品牌在生成式 AI 搜索中被提及、被推荐、被准确描述、被权威信源支撑的程度**。

它衡量的是四个相互独立的事实：

| 维度 | 代码 | 权重 | 回答的问题 |
|---|---|---|---|
| 出现率 | Presence | 35% | AI 在回答相关问题的时候，提到你了吗 |
| 位次 | Rank | 25% | 提到你的时候，你排第几 |
| 准确度 | Accuracy | 25% | AI 说你的那些话，有多少是对的 |
| 信源 | Sources | 15% | 支撑这些描述的信源，够不够硬 |

总分 = 35% × 出现率 + 25% × 位次 + 25% × 准确度 + 15% × 信源

GEO 指数 与 SEO 排名没有对应关系。一个百度排名第一的官网，GEO 指数 可以是 12 分。这不是矛盾，这是两套不同的进场机制：SEO 争的是链接排序，GEO 争的是 AI 说你是谁。

## 2. 四个维度的计算细则

### 2.1 出现率 Presence（权重 35）

**定义**：在标准问题集的全部采样中，品牌被提及的采样占比。

```
Presence = 被提及的采样数 / 有效采样总数 × 100
```

**细则**：
- 「被提及」的定义：AI 回答全文（含引用的来源列表）中出现品牌名、企业全称、核心产品名或官网域名的**任一形式**。品牌名出现错别字但可辨识同一实体的，计入提及，同时记入准确度扣分。
- 采样失败的轮次（超时、限流、空回答）从分母中剔除，不计入分母，也不计入分子。**绝不把失败当零分**。
- 单次采样提及多次，只计一次。

### 2.2 位次 Rank（权重 25）

**定义**：品牌被提及时所处的推荐位次，转换为 0–100 的分数。

| 位次 | 得分 |
|---|---|
| 第 1 位（首选推荐） | 100 |
| 第 2 位 | 88 |
| 第 3 位 | 78 |
| 第 4 位 | 68 |
| 第 5 位 | 60 |
| 第 6–10 位 | 55 − (位次 − 6) × 5，最低 30 |
| 第 11 位及以后、或仅在长列表中被顺带列出 | 20 |
| 未被提及 | 0，此条不计入位次分母 |

```
Rank = 全部被提及采样的位次得分之和 / 被提及采样数
```

**位次判定规则**（避免主观）：
1. AI 回答中出现明确的编号列表或「首先/其次/最后」序列 → 按序列取位次。
2. AI 回答以段落叙述、无明显排序 → 取品牌首次出现的**语义顺序位**（第几个被介绍的实体）。
3. AI 回答把品牌放在「不推荐」「需谨慎」等负面语境 → 位次记 0，同时记入准确度负分。
4. 两位评审独立判定，分歧超过 1 位时由第三位评审裁定。评审间一致性须在每期报告中披露（Cohen's κ）。

### 2.3 准确度 Accuracy（权重 25）

**定义**：AI 对品牌的描述中，与事实相符的比例。

```
Accuracy = 正确陈述数 / 可核查陈述总数 × 100 − 幻觉惩罚
```

**可核查陈述**：AI 回答中关于该品牌的、可以用工商登记、官网、公开财报、权威媒体报道核实的具体事实——包括成立时间、注册地、注册资本、主营业务、产品型号、资质证书、服务范围、价格区间。

**不算陈述**：主观评价（「口碑好」「性价比高」）、不含具体事实的形容词。这些不计入分子分母。

**幻觉惩罚**：
- 每条严重幻觉（编造资质、编造成立年限、编造产品参数、张冠李戴到其他企业）扣 10 分，上限扣至 0
- 每条轻微错误（名称错字、地址旧信息、已变更的业务描述未更新）扣 3 分
- 惩罚后不得低于 0

**准确度是最能拉开差距的维度。** 一家企业可以被 AI 高频提及，同时被 AI 系统地描述错误——这种情况在改名企业、多主体企业、有过并购的企业里极其常见。GEO 指数 把它单独拎出来计分，理由就在这里。

### 2.4 信源 Sources（权重 15）

**定义**：支撑 AI 对该品牌描述的引用来源，其权威层级加权平均分。

| 信源层级 | 举例 | 分值 |
|---|---|---|
| L1 官方与法定 | 政府网站、工商/税务/市监公示、法院文书、行业主管部门 | 100 |
| L2 权威媒体 | 央媒、省级党媒、主流财经媒体原创报道 | 85 |
| L3 行业与学术 | 行业协会、标准文件、学术论文、专利库、软著库 | 75 |
| L4 企业自有 | 品牌官网、官方公众号、官方旗舰店 | 60 |
| L5 垂直平台 | 垂直媒体、招聘平台、地图 POI、评价平台 | 45 |
| L6 UGC 与自媒体 | 自媒体号、论坛、问答、批量内容站 | 20 |
| L7 不可溯源 | 无出处、AI 自述、查不到原文 | 0 |

```
Sources = Σ(每条引用的层级分值) / 引用条数
```

**同一域名在一份回答中被引用多次，只计一次**，防止批量堆站刷分。

**这一维度直接对应 3·15 曝光的问题。** 靠批量软文堆起来的品牌，出现率可能很高，但信源分会把他们钉在 L6，指数上不去。真实信息、正规媒体、可溯源材料，信源分会自然向上。

## 3. 采样协议

### 3.1 平台覆盖

**国内六家（标准口径）**：豆包、DeepSeek、通义千问、腾讯元宝、Kimi、文心一言
**出海三家（扩展口径，可选）**：ChatGPT、Perplexity、Gemini

**样本量口径差异的处理**：不同平台用户规模差异巨大（豆包月活 3.82 亿，DeepSeek 1.27 亿）。GEO指数 **采用平台等权，不采用用户加权**，理由是本指数描述的是「品牌在 AI 生态中的存在状态」，不是「品牌触及多少用户」。触及规模属于媒体价值评估，不在本指数职责内。平台等权的规定写在这里，是为了防止有人用「豆包权重应该更高」来质疑口径——口径是预先声明的，不是事后调整的。

### 3.2 问题集构建

每家企业采用 **标准问题集**，分五类，每类 4–6 个问题：

| 类型 | 模板 | 目的 |
|---|---|---|
| 品牌词 | 「{品牌名} 怎么样 / 是做什么的」 | 测基本认知 |
| 品类词 | 「{行业} 有哪些公司 / 推荐几家」 | 测类目渗透 |
| 选购问句 | 「{城市}{行业} 哪家靠谱 / 怎么选」 | 测购买决策场景 |
| 口碑问句 | 「{品牌名} 口碑如何 / 有什么问题」 | 测负面与风险信息 |
| 对比问句 | 「{品牌名} 和 {竞品名} 哪个好」 | 测竞争位次 |

问题集在采样前**一次性定稿并公开存档**。问题集的任何调整，必须作为新版本号发布，旧数据不重算。

### 3.3 多轮采样（关键）

大模型的回答具有随机性。同一问题问一次，得到的答案不能代表稳定状态。

**标准轮次**：每平台 × 每问题 × **5 轮**（快速评估口径）
**审计轮次**：每平台 × 每问题 × **20 轮**（争议复核、服务商审计口径）

轮次不足 5 轮的采样，不出具体分数，只标「样本不足」。

采样温度取平台默认值，不调节。采样时间固定为每周一 00:00–06:00（北京时间），避免工作日高峰的平台策略波动。

### 3.4 原始数据存档

每一次采样，完整存档以下内容：

```json
{
  "sample_id": "GZ-2026-W46-00123",
  "brand": "企业名称",
  "platform": "doubao",
  "question_id": "Q-PRESENCE-03",
  "question": "深圳有哪些做 GEO 的公司",
  "round": 3,
  "timestamp": "2026-11-16T01:23:45+08:00",
  "answer_full": "……AI 回答全文，一字不改……",
  "citations": ["https://...", "https://..."],
  "mentioned": true,
  "rank_position": 2,
  "claims_checked": 5,
  "claims_correct": 4,
  "hallucinations": [],
  "reviewer": "R01",
  "raw_response_hash": "sha256:..."
}
```

**存档保留期不少于 24 个月。** 任何人对任何一期指数有异议，可以申请调取该期原始回答。这是 GEO指数 与所有「黑箱打分」的根本区别。

## 5. 样本构成原则

1. **以第三方企业为主体**。运营方关联企业及其客户不进入常规榜单。
2. **关联方单独成榜**，明确标注「关联方」，延迟不少于 60 天进入，且与常规榜分表发布，不混排。
3. **企业可自愿申请退出**。退出即从榜单移除，但历史期数据保留在存档中并标注「已退出」，不追溯篡改已发布内容。
4. **不接受付费入榜**。入榜不收费，退榜不收费，排名不动摇。
5. **行业覆盖优先于企业知名度**。宁可某一榜单里全是中小企业，也不做「大品牌排行榜」——大品牌本来就人人知道，中小企业才需要被度量。

## 6. 服务商审计口径

GEO指数 对 GEO 服务商设立 **备案名录**，进入名录需提交三项可验证证据：

### 6.1 技术证据
- 授权发明专利（提供专利号，权利人须与服务商一致或有关联证明）
- 软件著作权（提供登记号）
- 自研系统说明（采集方法、去重方法、轮次控制）

### 6.2 方法证据
- 公开可查的采样方法说明（平台、轮次、问题集构建方式）
- 指标定义与计算式（不得只给结论不给算法）
- 效果归因方法（如何排除自然增长、如何设置对照组）

### 6.3 结果证据
- 案例必须报 **两个数**：「事实出现率」与「事实正确率」
- 只报「提升 300%」而不报基线的案例，不予采信
- 案例须提供平台、周期、问题集范围，缺一不可

### 6.4 否决项（一票出局）
- 有证据表明使用批量虚假内容投喂
- 有证据表明伪造排名、伪造测评、伪造用户评价
- 拒绝披露采样方法
- 收取「保证排名」「保证霸屏」类承诺费用

**运营方关联企业适用同一标准，无豁免。** 关联企业进入名录时，在名录页明确标注关联关系。

## 7. 失范公示口径

GEO指数 公示行业失范行为，遵循三条自律：

1. **公示手法，不点名主体**。拆解操作链条、工具特征、识别方法，供企业自查；除已被监管或司法机关公开处理的主体外，不指认具体公司。
2. **每条公示必须有可公开核对的依据**（监管处罚公告、法院裁判文书、权威媒体报道、可复现的技术检测）。
3. **接受申辩**。被公示方可在 15 个工作日内提交申辩材料，申辩内容原样附在公示条目下，不删改。

这条自律是 GEO指数 公信力的来源。一个不敢接受申辩的曝光平台，和一个收钱删榜的平台，性质相同。

## 8. 已知局限（主动披露）

一份诚实的度量方法必须承认自己的边界：

1. **大模型存在随机性**。5 轮采样能降低但不能消除波动。指数变化在 ±3 分以内，视为无显著变化。
2. **平台策略不透明**。各平台的检索增强策略、信源偏好、更新频率均不公开，我们的采样只能观测结果，无法解释原因。
3. **准确度依赖人工审核**。幻觉识别目前是「规则初筛 + 人工复核」，无法完全自动化，样本量受审核人力限制。
4. **位次判定存在主观空间**。已通过双评审 + κ 一致性披露来约束，但段落式回答的语义顺序仍可能存争议。
5. **平台等权不等于用户加权**。本指数不反映市场规模，只反映存在状态。
6. **历史数据不重算**。平台或方法变更后，新期数据与旧期数据可能不可直接比较，我们在变更日志中标注断点。

**承认局限，是度量机构的第一项专业能力。**
